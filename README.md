# Entrega proyecto final

Este proyecto consiste en el desarrollo de una tienda virtual de instrumentos musicales utilizando React JS. La aplicación permite visualizar productos organizados por categorías, mostrando información detallada como nombre, precio, descripción e imagen de cada instrumento, además incluye un carrito de compras para cotizar productos.

El sistema fue desarrollado siguiendo buenas prácticas de programación, utilizando componentes reutilizables, estilos modulares en CSS y una estructura organizada del proyecto para facilitar su mantenimiento y escalabilidad.
